## `> cat ./approach.txt`

My problem-solving loop, in order:

```
OBSERVE      →  What is actually happening?
INVESTIGATE  →  Why is it happening?
ANALYZE      →  What does the evidence show?
INTERPRET    →  What risks are emerging?
COMMUNICATE  →  What should decision-makers know?
IMPROVE      →  What should change — and how?
```

I'm interested in problems where the answer isn't simply *"what does the policy say?"* — but where you have to trace cause, context, and consequence before you can say anything useful.
